贝壳币指南

先找明确写有“贝壳币奖励”的当期任务，再行动。

当期任务 查看 A+、Link 的消息、任务和活动入口，优先做已标明奖励的任务。
房源奖励 关注房源维护、推广和跨店成交类活动，按当期任务要求完成。
服务与榜单 关注服务质量、信用或贝壳分激励，以及城市榜单活动。
城市专项活动 参加城市发布的培训、竞赛和阶段性运营活动，以活动页规则为准。
每天这样找 A+ / Link → 消息、任务或活动 → 找“贝壳币奖励” → 核对城市、身份、截止时间和奖励上限 → 完成任务

币值和有效期会变化，以当天活动页为准。完成后可在 A+ / Link → 我的 → 个人钱包查收。
